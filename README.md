Proyecto elaborado en Python, utilizando la consola para registrar, consultar y procesar los datos
de pacientes. Proyecto final de Programación I, Universidad CES.

#Integrantes
- Sofia Ramirez Herrera
- Carlos Mateo Gomez Ocampo
- Mary Alejandra Martinez Garcia

#Funciones
1. Registrar paciente: pide id, nombre, edad, sexo y uso de corrección visual.
2. Consultar paciente: busca por id y muestra toda su información.
3. Mostrar pacientes registrados: muestra los nombres.
4. Buscar pacientes con corrección visual: muestra los nombres de quienes usan.
5. Generar estadísticas: total de pacientes, edad promedio y cantidad con
   corrección visual.
6. Salir.

El menú se repite hasta que el usuario elige la opción 6 y los datos de las personas nuevas que se registren se guardan de forma permanente en el archivo json.

#Archivos
- main.py: código fuente del programa.
- pacientes.json: registros ficticios de 5 pacientes para pruebas.

#Instrucciones de ejecución
1. Instalar Python 3.
2. Descargar o clonar este repositorio.
3. Abrir la carpeta del proyecto en la terminal.
4. Ejecutar: python main.py
5. Elegir una opción del menú escribiendo su número.
